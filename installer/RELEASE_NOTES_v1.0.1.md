## DocMind v1.0.1 更新说明

### 🌟 全新特性 (New Features)
- **🕸️ 知识图谱实体 Copilot 工作台**：
  - AABB 物理胶囊徽章防重叠引擎，双向贝塞尔分离，画布清晰无遮挡；
  - 450px 黄金宽度工作台：本地原著切片速览（Ground Truth）、关联网实体拓扑双向下钻、自适应智能快捷探索气泡；
  - ✨ **一键提炼精炼知识卡片**：多轮探讨成果一键结构化沉淀入库。
- **🤖 Copilot Agent 深度专家思维准则**：
  - 重构系统提示词，具备架构师深度逻辑，结合工程上下文剖析设计考量、核心机制、最佳实践与踩坑防范；
  - 回答末尾主动提炼「💡 架构洞察 / 知识沉淀建议」。
- **🌐 实时免 Key 联网技术资料融合**：
  - 内置 WebSearchService，在实体探讨时实时检索业界最新方案，与本地切片双轨溯源。
- **🧹 知识库自主整理引擎 (Curator)**：
  - 支持 `enrich`（智能打标）、`categorize`（自动归类）、`dedup`（语义去重）、`consolidate`（精炼蒸馏）；
  - 支持 `dry_run=true` 预览模式，安全透明。

### 🐞 问题修复与稳定性提升 (Bug Fixes & Improvements)
- 彻底修复国产大模型（商汤 SenseNova、DeepSeek 等）流式调用末尾 chunk 导致的 `list index out of range` 异常；
- 修复后端子进程管道缓冲区满导致的死锁挂起问题，启动速度压缩至 1 秒内；
- 修复 `ChatMessage` 缺少 `IsAssistant` 属性引起的 WPF 绑定报错；
- 修复设置页 GPU 加速包一键安装参数与 Windows 子进程无窗口调用异常；
- 强制清除 WebView2 磁盘与内存缓存，保证最新画布与抽屉栏 100% 渲染。

### 📦 安装与运行
- **免安装绿色版**：下载 `DocMind-v1.0.1-win-x64.zip`，解压即可直接运行（内置 .NET 8 独立运行时，无需额外配置环境）。
- **安装包**：下载 `DocMind-Setup-1.0.1.exe`，双击安装到开始菜单和桌面（推荐）。
