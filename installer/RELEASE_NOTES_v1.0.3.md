## DocMind v1.0.3 更新说明

### 🗄️ 存储后端中立化（PostgreSQL / pgvector 支持）

- **后端无关存储契约**：新增 `KnowledgeStore` 协议与能力声明，SQLite 与 PostgreSQL 实现同一套接口，上层业务零改动切换存储后端。
- **PostgreSQL 存储适配**：新增 PostgreSQL/pgvector 存储实现（连接生命周期与查询整形内聚，写入不变量收敛到批写器），支持配置 `postgres_dsn` / `postgres_tenant_id` / `postgres_index_generation` 启用；**默认仍走 SQLite，老用户零迁移成本**。
- **配套部署资产**：随仓库提供 `deploy/postgres/`（docker-compose + init.sql + schema.sql），一条命令起库。
- **跨后端快照格式**：新增知识库快照（ZIP 容器 + 清单 + 确定性 JSONL），与「备份（SQLite 恢复件）」职责分离，不同存储后端之间可互相导入；向量数据视为可选缓存，无法直接消费时自动重建索引。

### 🤖 Agent 任务化：后台任务与崩溃续跑

- **后台任务持久化**：Agent 长任务改为可持久化的后台任务（任务状态存储与用户问题分离，任务规格不污染检索 query）。
- **崩溃续跑**：客户端崩溃或关闭后重启，自动重连进行中的 Agent 任务并恢复进度展示，长任务不再因窗口关闭而丢失。
- **弱模型也能跑 Agent**：服务端 Agent 流式运行时（规划 → 执行 → 轨迹回放 → 流式生成）**不依赖大模型原生 tool-calling 能力**，小参数本地模型、无 tool-calling 的国产模型也能走完整 Agent 链路。

### 💬 对话体验：记忆隔离与可信证据

- **用户记忆隔离注入**：记忆以独立上下文块注入生成，明确框定为「用户偏好/背景，不是本轮问题主题」——不再拼进检索 query，通识题不再被库内噪声带偏主题。
- **任务规格**：研究任务的目标 / 受众 / 交付物 / 引用风格 / 约束与用户问题分离传递，弱模型下主题不漂移。
- **HTML 答案气泡**：答案 HTML 统一渲染，暗色主题自动跟随，溢出不再裁切错位。

### ⚡ 解析与模型管理

- **PDF 快检快抽**：新增 pypdfium2 文本层探测与快速抽取，秒级区分文字版 / 扫描版 PDF。
- **OCR 模型统一管理**：模型目录统一到 `%LOCALAPPDATA%/doc2mind/paddle_models`，默认走国内源（ModelScope，可切 BOS），首次使用前缓存检测 + 显式下载，不再依赖 HuggingFace 连通。

### 📦 安装与交付

- **修复绿色版 ZIP 缺 Python 运行时**：v1.0.2 的绿色版 ZIP 因打包环节静默跳过缺失的便携运行时，解压后后端无法启动；**本版绿色版 ZIP 内含完整 `python\` 便携运行时**（内置全部依赖，无任何路径绑定，解压即用）。
- **标准安装包**：`DocMind-Setup-1.0.3.exe`（PerUser 安装，无需管理员权限；可选勾选 GPU 加速 / OCR 识别组件，安装时联网下载）。

### ⬆️ 升级注意

- **直接覆盖安装即可**：用户数据（知识库 / 设置 / 聊天记录）位于 `%LOCALAPPDATA%` 与 `%APPDATA%`，不受影响。
- **v1.0.2 绿色版 ZIP 用户**：该 ZIP 缺少便携 Python 运行时，请改用本版 ZIP 或标准安装包。
- **首次启动**：需联网完成首次模型下载（内置国内镜像）；完全离线环境请预先拷贝模型缓存目录。

### 🐞 已知问题与规避

- PostgreSQL 后端当前通过配置文件 / 环境变量启用（`postgres_dsn` 等），设置界面开关将在后续版本提供；不配置则默认使用 SQLite，功能不受影响。
- GPU / OCR 可选组件体积较大（约 2GB / 1.5GB），安装时勾选需保持联网；不勾选则核心功能（检索 / 对话 / 图谱）完整可用。
