# DocMind 新设备部署指南

> 目标：把 DocMind（Python 后端 + WPF 桌面客户端）从零部署到一台新的 Windows 设备，
> 且功能与开发机一致、稳定运行。
>
> 适用版本：7.30.1.0000.3（git 分支 debug，HEAD 5a54551）
> 文档更新：2026-08-07
> 许可证：AGPL-3.0（开源，商业使用需遵守 AGPL 源代码公开义务；如需闭源可获取商业授权）

---

## 一、部署前须知（重要）

| 事项 | 说明 |
|------|------|
| 环境锁定 | 依赖已锁定在 `requirements-*.txt`（开发机验证过的精确版本），**不要**用 `pip install doc2mind` 自由解析 |
| GPU 特例 | 开发机是 RTX 2060 + 驱动 595.79（CUDA 13.2），onnxruntime-gpu 1.28(cu13) 与 paddlepaddle-gpu 3.3.1(cu126) **两套运行时共存**，这是特例。普通新设备建议**单一运行时**（见下文"GPU 选择"） |
| 网络 | 国内网络 HF 直连超时：模型下载内置 `hf-mirror.com` 镜像；pip 走清华镜像；大 whl（paddle ~300MB）建议 curl 断点续传 |
| 磁盘 | 全功能安装 + 模型缓存约需 **6~8GB**（paddle ~2GB、onnxruntime ~0.5GB、nvidia 运行时 ~2GB、模型 ~90MB） |
| 系统 | Windows 10/11 x64；Python 3.10~3.12（推荐 3.11，与开发机一致）；WPF 客户端需 .NET 8 SDK（仅构建需要，发布后为自包含 exe） |

## 二、快速开始（推荐路径）

```powershell
# 1. 安装 Python 3.11（勾选 "Add python.exe to PATH"）
#    https://www.python.org/downloads/

# 2. 克隆代码
git clone <你的仓库地址> DocMindY
cd DocMindY

# 3. 一键部署（core 全功能以外的东西按需选择）
powershell -ExecutionPolicy Bypass -File scripts/setup.ps1 -All   # 全功能（推荐）
# 或按需：
powershell -ExecutionPolicy Bypass -File scripts/setup.ps1            # 仅 core
powershell -ExecutionPolicy Bypass -File scripts/setup.ps1 -Gpu -Ocr  # GPU 嵌入 + OCR

# 4. 启动后端
.\.venv\Scripts\doc2mind.exe serve      # HTTP 服务 localhost:8765
# 或 MCP：
.\.venv\Scripts\doc2mind.exe mcp

# 5. （可选）构建 WPF 客户端
cd WpfApp1
dotnet build -c Release                  # 输出 bin\Release\net8.0-windows\win-x64\publish\DocMind.exe
```

`setup.ps1` 会依次：检查 Python 版本 → 创建 `.venv` → 用**锁定版本**安装依赖（清华镜像）→
editable 注册 `doc2mind` → 导入冒烟 + 跑全部 pytest。全部通过即部署成功。

## 三、打包安装包（Inno Setup）

用于给外部用户分发，用户双击安装即可使用。

### 3.1 前置条件

1. 安装 [Inno Setup 6](https://jrsoftware.org/isinfo.php)（免费）
2. 确保 `.venv` 已就绪（运行过 `setup.ps1 -All`）
3. 确保 WPF 已发布 Release 版本：

```powershell
dotnet publish WpfApp1/DocMind.csproj -c Release -r win-x64 --self-contained true /p:PublishSingleFile=true /p:EnableCompressionInSingleFile=true
```

### 3.2 编译安装包

1. 打开 Inno Setup Compiler
2. 加载 `installer/docmind-setup.iss`
3. 点击「Build → Compile」或按 `Ctrl+F9`
4. 输出文件：`installer/Output/DocMind-Setup-{version}.exe`

### 3.3 安装包内容

| 组件 | 说明 |
|------|------|
| `DocMind.exe` | WPF 单文件自包含 exe |
| `.venv/` | Python 虚拟环境（含所有依赖） |
| `Assets/` | 图标等资源 |
| `appsettings.json` | 配置文件 |
| `scripts/setup.ps1` | 部署脚本 |

### 3.4 安装流程

1. 用户双击 `DocMind-Setup-{version}.exe`
2. 选择安装目录（默认 `Program Files\DocMind`）
3. 创建桌面快捷方式（可选）
4. 安装完成可选立即启动

> **注意**：安装包已包含完整的 Python 环境，用户**无需**单独安装 Python。

## 四、GPU 选择（重点，决定"稳定"还是"踩坑"）

DocMind 有两处用到 GPU：**嵌入推理**（onnxruntime）和 **OCR**（PaddlePaddle）。

### 3.1 普通设备（无 NVIDIA 显卡，或不想折腾 GPU）

最简单、最稳定：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/setup.ps1            # 仅 core
# 嵌入自动用 CPU（约 200 texts/s，够用）；OCR 可不装或装 CPU 版
```

- 嵌入：`fastembed` 默认 CPU，无需任何配置。
- OCR（可选）：把 `requirements-ocr.txt` 里的 `paddlepaddle-gpu==3.3.1` 一行**删掉**再装，
  pip 会自动装 CPU 版 `paddlepaddle`（PaddleOCR 在 CPU 上可用，扫描件逐页 OCR 较慢）。
- 优点：**无 cu12/cu13 运行时共存问题，最不容易出幺蛾子**。

### 3.2 有 NVIDIA 显卡（推荐路径）

```powershell
# 嵌入 GPU：安装 onnxruntime-gpu
pip install -r requirements-core.txt -r requirements-gpu.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

- 驱动要求：onnxruntime-gpu 1.28 官方轮子是 **CUDA 12.x** 构建，装普通 NVIDIA 驱动即可。
- 代码会自动探测：找到可用 CUDA EP 就用 GPU，否则**自动回退 CPU**（不会崩）。
- 若驱动是 CUDA 13.x 以上（如开发机的 595.79 / CUDA 13.2），需要 cu13 构建的
  `onnxruntime_gpu-1.28.0-cp311-cp311-win_amd64.whl`（开发机验证过），
  用 curl 断点续传下载后 `pip install <whl>`，见 `requirements-gpu.txt` 注释。

### 3.3 OCR GPU（可选，仅在嵌入 GPU 已就绪时）

```powershell
# paddlepaddle-gpu 3.3.1 (cu126)，whl 约 300MB，国内 pip 常停滞：
# 1) 从阿里云/清华镜像下载：
#    curl -C - -L -o paddlepaddle_gpu-3.3.1-cp311-cp311-win_amd64.whl ^
#      https://mirrors.aliyun.com/paddlepaddle/3.3.1/win/paddlepaddle_gpu-3.3.1-cp311-cp311-win_amd64.whl
# 2) 本地安装：
pip install paddlepaddle_gpu-3.3.1-cp311-cp311-win_amd64.whl
```

> ⚠️ **运行时共存警告**：开发机把 onnxruntime-gpu（cu13）和 paddlepaddle-gpu（cu12）装在一起，
> 靠 `doc2mind.core.nvidia_runtime` 注册 DLL 目录 + cu13 预检才不崩。
> 新设备**没必要**复刻这种共存——要么只装 onnxruntime-gpu（嵌入 GPU、OCR 用 CPU），
> 要么只装 paddlepaddle-gpu（OCR GPU、嵌入 CPU）。这样最稳。

## 五、嵌入模型下载与离线部署

- 首次使用需联网下载 `BAAI/bge-small-zh-v1.5`（~90MB），代码**默认走 hf-mirror.com 镜像**，
  无需手动配置；下载失败会自动重试一次并给出中文指引。
- 缓存目录：`%LOCALAPPDATA%\doc2mind\fastembed_cache`。
- **离线设备**：把网络正常的机器上该目录**整体拷贝**到目标机同一位置（保留目录结构）即可，
  程序检测到已缓存就不再下载。

## 六、数据与配置位置（换机迁移）

| 内容 | 路径 | 说明 |
|------|------|------|
| 知识库（sqlite-vec） | `%LOCALAPPDATA%\doc2mind\doc2mind.db` | 全部文档分块与向量 |
| 配置 | `%APPDATA%\doc2mind\config.toml` | 嵌入模型/分块参数等 |
| 模型缓存 | `%LOCALAPPDATA%\doc2mind\fastembed_cache` | 可整体拷贝离线复用 |
| MCP 接入 | 见 `docs/mcp.md` | 注册到 Cursor/Claude Desktop 等 |

迁移：拷贝上述三个目录即可无缝换机；数据库路径也可用 `DOC2MIND_DB_PATH` 环境变量覆盖。

## 七、端口与后端进程

- 后端固定 `127.0.0.1:8765`；WPF 客户端启动时自动从应用目录向上找 `.venv` 拉起后端
  （找不到时用 PATH 里的 `doc2mind` / `python -m doc2mind`）。
- 端口被占用时：后端会自动 `+1` 探测空闲端口（见部署后版本的改动说明），
  WPF 侧通过 `/v1/health` 探测实际端口，两者会自动对齐。
- 若需手动指定后端命令，可在 `WpfApp1/appsettings.json` 设 `BackendCommand`，
  或环境变量 `DOC2MIND_CMD`。

## 八、常见问题排查

| 症状 | 原因 | 处理 |
|------|------|------|
| 嵌入报 `LoadLibrary failed` / WinError 126 | 多套 nvidia 运行时冲突 | 见 3.3 共存警告，退化为单一运行时 |
| 模型下载超时 | 直连 HF 被墙 | 内置镜像已处理；仍失败设 `DOC2MIND_HF_ENDPOINT=https://hf-mirror.com` |
| pip 装 paddle/onnxruntime 停滞 | 大包国内网络 | curl -C - 断点续传后本地装（3.3 示例） |
| 后端起不来，WPF 状态灯红色 | 端口占用 / .venv 找不到 / 依赖缺 | 看 WPF「调试日志」页；手动 `doc2mind serve` 看报错 |
| OCR 慢 | CPU 版 paddle | 换 GPU 版，或接受 CPU 速度 |
| 配置不生效 | Python 3.10 无 tomllib | 已加 tomli 回退；升级 3.11 更稳 |
