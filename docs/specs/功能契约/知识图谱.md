### 功能：知识图谱

**能完成的任务**（一句话，用户视角）：
查看已抽取出的实体—关系网络，点击实体查看关系、来源片段与来源文档，并可就实体深入对话、提炼知识卡片、沉淀入库。

**不能完成的事**（边界，防范围蔓延）：
- 不对未注入的文档自动建图（需先导入并「抽取图谱」）。
- 不保证所有文档都产出实体（`extracted_count` 可能为 0，`GraphViewModel.cs:400-408`，属正常）。
- 不做可视化交互的原生前端重实现（图谱渲染交给图谱视图，本 VM 只提供数据与事件，`GraphDataRenderRequested`）。

**前置条件**：后端在线 → 不满足时 `LoadGraphAsync` 置 `HasLoadError=true` 显示错误态（非误导为「暂无数据」，`GraphViewModel.cs:165-168,346-357`）；**LLM 未配置时「抽取图谱」应事前禁用**：
- ⚠️ **缺口 FC-06**：后端已有前置检查（未配置 LLM 直接 400，`http.py:3119`，返回 `LLM_NOT_CONFIGURED`），但 **UI 是点「抽取图谱」按钮后才提示**（`GraphViewModel.cs:389` 先把 `StatusMessage` 置「大模型正在…请稍候…」，请求返回 400 才报错）。没有任何 `IsLlmConfigured` 属性（对比 `ChatViewModel.cs:946`），按钮未事前禁用、未见「前往配置大模型」引导。参照样本可加 `IsLlmConfigured` + 禁用 + `NavigateToSettingsRequested` 范式（FC-06）。

**输入契约**：可选集合 `Collection`（默认「全部集合」）；实体快速跳转下拉（`SelectedEntityJumpName`，命中时聚焦节点并开档案，`GraphViewModel.cs:70-82`）；实体对话输入 `EntityChatInput` + `IsWebSearchEnabled`。空选择不触发（`JumpToEntity` 对未命中静默返回）。

**状态机**：
- 图谱加载：`idle → loading → loaded(hasGraph) | loaded(empty) | error`(`LoadGraphAsync` + `hasLoadOnce` 缓存，`GraphViewModel.cs:299-362`)。
- 抽取：`idle → extracting → succeeded(extracted>0 / 0/部分失败提示) | failed`（`ExtractGraphAsync`，`GraphViewModel.cs:386-442`）。
- 实体对话：`idle → streaming → done | cancelled | failed`（`IsEntityAiGenerating` 控制，`GraphViewModel.cs:118-129`）。

**4 个出口**
- ✅ 成功：图谱节点/边渲染（`HasGraph` = `TotalNodes > 0`，`GraphViewModel.cs:203,335`）；抽取成功弹「成功从 N 篇文档中抽取实体并构建图谱」（`GraphViewModel.cs:398`）；实体对话流式渲染；提炼卡片弹窗展示（`DistillEntityCardAsync`，`GraphViewModel.cs:1100`）。完成判据：图谱 `nodes/edges` 有值；抽取 `result.Ok && ExtractedCount > 0`。
- ⚠️ 失败：
  - 图谱加载：`HasLoadError` 显示错误态 + `StatusMessage`「加载图谱失败: …」，区别于空态（`GraphViewModel.cs:346-357`）。
  - 抽取：`ApiException` 时 `StatusMessage`「提示: …」（`GraphViewModel.cs:420-425`）——根因是 FC-06 前置未拦截（见前置条件），点按钮后才提示；`BackendConnectionException` → 页内「无法连接到后端服务…」（`GraphViewModel.cs:426-431`）——与 FC-03/FC-08 同类，未走全局离线横幅（未编号）。
  - 实体对话失败 → 气泡「⚠️ 抱歉，AI 问答出现异常: …」（`GraphViewModel.cs:828-836`）。
  - 「下一步」：修复后端 / 去设置配置 LLM（FC-06 落地后「抽取」按钮将事前禁用）。
- ✅ 取消：实体对话「停止」（`StopEntityChat`，`GraphViewModel.cs:922-926`）→ `_chatCts.Cancel()` → `OperationCanceledException` 处理，气泡追加「*(已手动停止生成)*」（`GraphViewModel.cs:820-827`）；切换节点/关闭详情/清空对话均 `_chatCts.Cancel()`（`GraphViewModel.cs:462,1303,929`）。抽取任务无可取消路径。
- ✅ 空态：`ShowEmptyGraph`（`GraphViewModel.cs:165`）= 非忙碌、无错误、`TotalNodes==0` 时，状态区「当前分组暂无图谱数据（可点击「抽取图谱」构建）」（`GraphViewModel.cs:341`）——是「空态」而非错误；有实例无关联时详情区给出空态提示（`HasRelations/HasSnippets/HasSourceDocuments`）。

**恢复路径**：图谱加载失败后 `_hasLoadedOnce` 不置位（`GraphViewModel.cs:257`, `EnsureLoadedAsync` 在 `_loadSucceeded` 时才 `_hasLoadedOnce=true`），下次进入自动重试；`InvalidateCache`（`GraphViewModel.cs:265`）供导入后失效重载；实体对话失败可改问/重发。

**可执行测试**：
- `Given LLM 未配置 When 进入图谱页 Then 抽取按钮为禁用态 且可见「前往配置」引导`（❌ 当前为点后才提示，FC-06）
- `Given LLM 已配置 When 点抽取 When 有实体则 Then 通知成功 且图谱刷新有节点`
- `Given 空库 When 加载图谱 Then 显示「暂无图谱数据」空态（非错误）`
- `Given 图谱加载失败 When 后端异常 Then 显示错误态 区别于空态`
- `Given 实体对话生成中 When 点停止 Then 气泡追加「已手动停止生成」且内容保留`
