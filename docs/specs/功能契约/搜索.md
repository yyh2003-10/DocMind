### 功能：搜索

**能完成的任务**（一句话，用户视角）：
输入自然语言或关键词，从已导入的知识库中检索到最相关的文档片段，并定位到原文、据此发起对话。

**不能完成的事**（边界，防范围蔓延）：
- 不生成答案（那是「对话」功能）；本功能只返回命中片段与相关度。
- 不区分正确写法/纠错（按输入词做向量 + BM25 混合检索）。
- 「库为空」与「库有内容但无命中」当前**不区分**（见空态出口，FC-07）。

**前置条件**：后端在线 → 不满足时走全局离线横幅（FC-08，未统一），页内 `StatusMessage` 显示「后端不可达：…」（`SearchViewModel.cs:385`）。集合列表异步加载失败时静默使用默认项（`SearchViewModel.cs:83-86`）。

**输入契约**：搜索词 `Query`（字符串）；可选集合 `Collection`（默认「(全部集合)」）；`TopK`（默认 10）；`MinScore`（可选最低相似度，null = 不过滤）。空输入时搜索按钮禁用（`CanSearch`，`SearchViewModel.cs:312`）；非法/空词不发起请求。历史搜索上限 20 条（`MaxSearchHistory`，`SearchViewModel.cs:32`）。

**状态机**：`idle → searching → done(succeeded) | done(empty) | failed`（前端 `IsBusy` 驱动）。

**4 个出口**
- ✅ 成功：`Hits` 填充命中结果，首条自动选中显示详情，选中后可「在文档库查看」（`OpenInDocuments`）或「基于此分块提问」（`AskInChat`，`SearchViewModel.cs:425-445`）；状态区显示「返回 N/M 条 · 耗时 X ms」（`SearchViewModel.cs:370-372`）；成功词记入历史。完成判据：`resp.Total > 0` 且 `Hits` 可视化呈现。
- ✅ 失败：`StatusMessage` 分别按 `ApiException` / `BackendConnectionException` / 未知异常给文案（`SearchViewModel.cs:376-393`）。「下一步」：后端离线 → 修复后端；加 `ToolCallResilience` 空结果重试（`SearchAsync`，`SearchViewModel.cs:337-351`）。
- ✅ 取消：语义上的「取消」= 发起新搜索或 `Clear()`（`SearchViewModel.cs:415-423`）复位到空；无长任务取消（搜索为短请求），后端不可用时由超时/异常捕获收敛。
- ⚠️ 空态：
  - ✅ 已区分「还没搜过」与「搜了没结果」：`EmptyGuideText`（`SearchViewModel.cs:227-229`）在 `HasQuery == false` 时提示「输入问题…还没导入文档？先到【导入】页添加文件」，在 `HasQuery == true` 时提示「没有匹配的结果。建议尝试更换关键词或以调低最低相似度…确认文档已加入知识库」。
  - ❌ **缺口 FC-07**：「库为空」与「有文档但无命中」两种空态**不区分**——两者都命中 `HasQuery == true` 分支的同一句「没有匹配的结果」。后端 `/v1/search`（`http.py:2028`）对两种情况都返回空 `hits`。出路动作也相同（都是引导换词/去导入页），未做到「不同文案 + 不同出路动作」。

**恢复路径**：失败后 `IsBusy` 复位、`StatusMessage` 给出原因，用户可改词重搜；`Clear()` 一键复位；后端恢复在线后在页内重新搜索即可（无持久状态需恢复）。

**可执行测试**：
- `Given 空库+输入词 When 搜索 Then 显示「库为空」类文案+去导入动作`（❌ FC-07：当前 `EmptyGuideText` 在 `HasQuery==true` 时统一显示「没有匹配的结果…」，空库与无命中未区分）
- `Given 有文档+无命中词 When 搜索 Then 显示「无匹配结果」+换词/调低最低相似度动作`（⚠️ FC-07：当前与「空库」共用同一句「没有匹配的结果…」，两条出路未分离）
- `Given 合法命中词 When 搜索 Then Hits>0 且首条自动选中 且词记入历史`
- `Given 空输入 When 搜索 Then 按钮禁用 不发起请求`
- `Given 选中 hit When 点「基于此分块提问」 Then AskInChatRequested 触发 携带引导提问`
