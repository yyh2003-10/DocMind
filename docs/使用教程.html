DocMind 使用教程

打开软件不知道该干什么？点完按钮不知道发生了什么？看这一篇就够 —— 每个页面"有什么、该做什么、点了之后发生什么"，全部讲清楚。

一、软件是干什么的（一句话）

核心概念

DocMind 是一个本地向量知识库：把你电脑里的文档（PDF / Word / Excel / PPT / Markdown / HTML / 图片 / 代码）导入后，自动切成小块（分块）、转成向量（嵌入）存进本地数据库。之后你可以用自然语言提问搜索，软件会从这些文档里找出最相关的内容，按相似度排序给你。

  • 全部计算在本地完成，文档不会上传到任何服务器。
  • 搜索 = 向量相似度 + 关键词（BM25）混合检索，两路结果融合排序（RRF）。
  • "后端"是指软件自动启动的一个本地 Python 服务（localhost:8765），所有操作都通过它读写知识库。状态灯在窗口左上角，绿色=在线，黄色=启动中，红色=离线。

三、逐页说明

默认首页 · 最常用的功能

🔍 搜索页

界面有什么 搜索框、集合输入框（可选）、结果条数下拉（5/10/20/50）、最低相似度输入框（可选）、"搜索"和"清空"按钮、左侧结果列表、右侧详情面板。
你该做什么 输入一段话（可以是一个问题，也可以是一句话），点"搜索"或按回车（Ctrl+K 也可快速回到本页）。
点了之后后台发生什么
  1. 后端把搜索词转成向量，在知识库所有分块里找语义最接近的；
  2. 同时做关键词匹配（BM25）；
  3. 两路结果融合排序，返回相似度最高的若干条。

怎么看结果：

  • 每条结果左上角是相似度分数（0~1，越高越相关；hybrid 表示向量和关键词都命中了，vector/bm25 表示只有一路命中）。
  • 点击某条结果，右侧显示该分块的完整原文、来源文件、格式、标题、匹配类型。
  • "最低相似度"填 0~1 的小数（如 0.3），可以过滤掉相似度太低的结果。
  • "集合"填导入时的分组名，就只在那一组文档里搜；留空搜索全部。
💡 觉得结果不准？试试：换更具体的关键词、调低最低相似度、或选更大的 Top-K（50 条）。
建立知识库的关键步骤

📥 导入页

界面有什么 路径输入框（支持直接拖拽文件/文件夹进来）、"选择…"按钮、集合名输入框、"递归子目录"勾选框、"导入"和"重置"按钮、进度条、结果三栏（成功 / 跳过 / 失败）。
你该做什么 选择或拖入一个文件或文件夹，可选填集合名（分组名），点"导入"。支持 8 种格式：PDF / Word / Excel / PPT / Markdown / HTML / 图片 / 代码。
点了之后后台发生什么（这是全软件最"重"的一步）
  1. 后端逐文件读取内容（PDF 逐页解析、Word/Excel/PPT 解析、图片 OCR 等）；
  2. 按语义把内容切成小块（分块），表格和代码块会被整块保护；
  3. 每个分块转成向量（嵌入）；
  4. 写入本地向量库；已导入过的文件（内容没变）自动跳过（MD5 去重）。

怎么看结果三栏：

  • ✅ 成功：每个文件的文件名 + 分块数 + 大小 + 格式。
  • ⏭ 跳过：内容与已导入的相同，不会重复入库。
  • ❌ 失败：显示具体是哪个文件、为什么失败（如"加载失败 / 分块失败 / 嵌入失败"）。
📌 集合是什么：给这批文档起的分组名。留空则归入 default。搜索时填同一个集合名，就只在那一组文档里搜 —— 相当于给知识库分区。例如"合同"、"论文"、"说明书"各一个集合。
⏳ 首次导入可能较慢：首次用某个嵌入模型要下载（国内走镜像）；扫描型 PDF 要逐页 OCR。进度条转圈时请耐心等待，不要关软件。
格式互转 · 不进知识库

🔄 转换页

界面有什么 源文件输入框 + "选择文件…"、输出位置输入框 + "另存为…"、格式下拉（md / json / txt / html）、"转换"和"重置"按钮、预览区。
你该做什么 选一个源文件（PDF / DOCX / XLSX / PPTX / MD / HTML 等），选目标格式，点"转换"。
点了之后后台发生什么 后端解析该文件 → 转成目标格式文本 → 返回内容；如果指定了输出位置，会直接写文件到那个路径（完成后状态栏会显示"已写入：路径"）；没指定输出位置则只在右侧预览，不落盘。
⚠️ 重要区别：转换只是改格式，不进入知识库 —— 转换结果不会出现在搜索结果里。想把文件加入知识库，请走【导入】页。
整体健康度体检

📊 质量看板页

界面有什么 集合过滤框 + "刷新"按钮；四张概览卡片；左侧集合分布列表；右侧警告列表。
你该做什么 点"刷新"，查看知识库整体健康度。

四张卡片分别是什么：

卡片含义
📄 文档总数知识库里有多少个文档
🧩 分块总数所有文档被切成多少块
🔁 格式分布出现过几种文档格式（如 pdf / docx / md）

集合分布：每个集合（分组）各有多少文档、多少分块、占用多大空间。警告列表会给出具体问题，例如：

  • "文档「xxx」分块数为 0，可能无法被检索到" → 该文档可能内容是纯图片/扫描件，建议检查原文件。

管理已导入的文档

🗂️ 文档库页

界面有什么 集合过滤框、分页按钮（◀ ▶）、"刷新"、"删除选中"、"重建索引"按钮；左侧文档列表（分页，每页 20 条）；右侧选中文档的分块预览。
你该做什么 浏览已导入的文档；选中一个文档看它的分块内容；删除不要的文档；或重建索引。
几个操作的说明
  • 删除选中：弹窗确认后，删除该文档及其全部分块和向量（不可恢复）。
  • 🔍 定位：在分块预览里点"定位"，会跳转到搜索页，用该分块内容作为搜索词，帮你找到相关知识。
  • 重建索引：把现有分块重新用嵌入模型计算一遍向量。什么时候用？
    • 在设置页换了嵌入模型之后；
    • 怀疑向量数据损坏，想整体刷新。
    点"重建索引"会提交一个后台任务，进度条显示处理进度（如"重建中 100/500 分块"）。重建期间不要关软件。
一般不用改

⚙️ 设置页

界面有什么 后端连接（地址、启动超时）、性能（轮询间隔）、模型与分块（嵌入模型、分块参数）、启动选项（自动拉起后端、退出联动终止、后端命令路径、自动导入目录）、外观（浅色/深色主题）、关于；底部"保存"和"恢复上次保存"按钮。
你该做什么 一般不用改，默认值就能用。需要时才调整，改完记得点"保存"。
配置作用何时改
后端地址后端服务地址后端端口变了，或改用远程后端
启动超时（秒）等待后端启动的最长时间机器很慢、首次下载模型时可能超时
任务轮询间隔后台任务进度刷新频率一般不用动
嵌入模型向量化用的模型（small / base / large）想提高检索精度（模型越大越慢、越占内存）
分块参数分块的大小 / 重叠量检索粒度不合适时微调
自动拉起后端启动客户端时自动启动后端想自己手动启动后端（取消勾选）
退出联动终止退出客户端时关掉后端想退出后后端继续运行（如让 MCP/CLI 继续用）
启动自动导入启动后自动导入某个目录常用目录想"开机即用"
主题浅色 / 深色按喜好切换（切换后会自动重启应用生效）
⚠️ 修改模型 / 分块 / 后端地址后：模型和分块参数保存后实时生效；但换了嵌入模型后，旧文档的向量还是旧模型算的 —— 记得去【文档库】页点"重建索引"重新计算，否则搜索结果会不准。
排错专用

📋 调试日志页

界面有什么 实时滚动的日志行、"清空缓冲"、"打开日志文件"、"打开日志目录"按钮。
你该做什么 平时不用看。当某个操作出错、状态栏提示"详见后端日志"时，来这里查原因；或点"打开日志文件"用文本编辑器打开完整日志文件。
📌 日志会记录每次搜索 / 导入 / 转换的请求与响应摘要（含耗时），排查"为什么慢"也很有用。

四、术语速查表

术语含义
集合 (Collection)文档的分组名。导入时指定，搜索/看板可按组过滤；留空归入 default
分块 (Chunk)文档被切开的一个个小片段，是搜索的最小单位
嵌入 / 向量 (Embedding)把文本转成数字向量，让计算机能算"语义相似度"
相似度分数0~1，搜索结果与搜索词的匹配程度，越高越相关
混合检索向量相似度 + 关键词（BM25）两路结果融合排序（RRF）
Top-K一次搜索最多返回多少条结果（5/10/20/50）
重建索引 (Reindex)用嵌入模型重新计算所有分块的向量（换模型后必做）
后端 (Backend)本地 Python 服务（默认 localhost:8765），负责解析/分块/嵌入/检索/存储
MD5 去重内容相同的文件只入库一次，重复导入会被"跳过"

五、常见问题

Q：搜索没有结果，为什么？

先到【导入】页确认文档已成功导入（没有全在"失败"栏）；再看集合是否匹配（搜索页集合要留空或与导入时一致）；最后可降低"最低相似度"、加大 Top-K 或换关键词。

Q：导入很慢 / 进度条一直转？

首次用某个模型需要下载（国内走镜像，几分钟）；PDF 扫描件要逐页 OCR；大文档耗时正常。进度条在等待后端完成整批处理，完成后会显示成功/跳过/失败明细。

Q：改了设置好像没生效？

模型和分块参数保存后实时生效；换了模型后记得去【文档库】重建索引。其余变更（如后端地址、自动导入目录）重启客户端后生效。

Q：左上角状态灯是红色 / 托盘图标显示"离线"？

后端没起来或连不上。若勾选了"启动时自动拉起后端"，稍等片刻（首次会下载模型，可能 1~2 分钟）；若取消了该选项，请手动运行 doc2mind serve 后再打开客户端。

Q：删除文档会怎样？

会同时删除该文档的全部分块和向量（释放空间），不可恢复。删除前有确认弹窗，请看清再点确认。

Q：重新导入同一个文件会重复吗？

不会。后端按文件内容 MD5 去重：内容没变的文件会被"跳过"，只有内容变化过才会重新入库（新版本会替换旧版本）。想强制重新导入，可先到文档库删除旧文档再导入。
