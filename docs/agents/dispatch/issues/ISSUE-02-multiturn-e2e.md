## 背景用户反馈：「上句说了什么，下句就不记得」。  
已修：失败轮写入历史、多轮提示、记忆禁止当引用。需真机验证。

## 验收标准

- [ ] **同会话**连续两问，第二问能正确指代第一问对象（如「挠度」→「它的单位」）  
- [ ] 第一问**故意失败**（错 Key/断网）后，第二问同一会话仍知「上句问了什么」或有失败占位  
- [ ] **停止**后历史：不把半截正文当完整 assistant；用户问题仍可追溯  
- [ ] 重启后端后，打开历史会话仍能多轮  
- [ ] 调试日志可见 chat_id 贯穿；无 done 时有「未获得 chat_id」警告场景记录  

## 建议场景

1. gpt-oss/DeepSeek + 本地 PDF：问定义 → 追问单位/公式  
2. nemotron 失败后再问  
3. 新建对话 vs 历史会话对比
