# DocMind 使用说明 —— 每个页面在干嘛

> 面向使用者的操作指南。想知道"打开软件该干什么、点了之后发生什么"，看这一篇就够了。

---

## 一、软件是干什么的（一句话）

**DocMind 是一个本地向量知识库**：把你电脑里的文档（PDF / Word / Excel / PPT / Markdown / HTML / 图片 / 代码）
导入后自动切成小块（分块）、转成向量（嵌入）存进本地数据库，之后你可以**用自然语言提问搜索**，
软件会从这些文档里找出最相关的内容，按相似度排序给你。

- 全部计算在**本地**完成，不上传文档。
- 搜索 = **向量相似度 + 关键词（BM25）混合检索**，两者结果融合排序（RRF）。
- "后端"是指软件自动启动的一个本地 Python 服务（`localhost:8765`），所有操作都通过它读写知识库。

## 二、推荐使用流程（按这个顺序用）

```
① 设置   → ② 导入   → ③ 搜索 / 对话   → ④ 文档库 / 质量看板（管理、检查）
```

1. **设置**：确认后端地址正确（默认 `http://127.0.0.1:8765`），可调整嵌入模型与分块参数。
2. **导入**：把文档或文件夹拖进"导入"页（或点"选择…"），点"导入"，等进度条走完。
3. **搜索**：输入问题，选择要搜的分组（或留空搜全部），点"搜索"，看结果。
4. **文档库**：浏览已导入的文档、看分块、删除文档、重建索引。
5. **质量看板**：看知识库整体统计（文档数 / 分块数 / 格式分布 / 质量警告）。

> 第 2 步是第 3 步的前提：**没导入文档，搜索是搜不出东西的。**

## 三、逐页说明

### 🔍 搜索页

**界面有什么**：搜索框、分组输入框（可选）、结果条数下拉（5/10/20/50）、最低相似度输入框（可选）、"搜索"和"清空"按钮、左侧结果列表、右侧详情面板。

**你该做什么**：输入一段话（可以是问题，也可以是一句话），点"搜索"或按回车。

**点了之后后台发生什么**：
1. 后端把搜索词转成向量，在知识库所有分块里找语义最接近的；
2. 同时做关键词匹配（BM25）；
3. 两路结果融合排序，返回相似度最高的若干条。

**怎么看结果**：
- 每条结果左上角是**相似度分数**（0~1，越高越相关，`hybrid` 表示向量和关键词都命中了）。
- 点击某条结果，右侧显示该分块的完整原文、来源文件、格式、标题。
- "最低相似度"输入 0~1 的小数（如 `0.3`），可以过滤掉相似度太低的结果。

**注意**：如果搜索"无匹配结果"，先确认是否已导入文档，或尝试换关键词、调低最低相似度。

### 💬 对话页（RAG 智能问答 · 启动默认首页）

**界面有什么**：左侧历史会话列表（可新建/切换/删除）、中间消息气泡区（支持 Markdown 渲染与来源引用角标）、底部输入框；知识库勾选区（多选分组）、模型选择、「联网」模式（关闭 / 普通搜索 / 深度搜索）、「停止生成」按钮。

**你该做什么**：先在【设置】页配好大模型（服务商 / API Key / 模型），再回这里提问。

**点了之后后台发生什么**：
1. 后端在你勾选的知识库分组里做混合检索（向量 + BM25）；
2. 命中片段作为上下文连同多轮历史一起送给大模型；
3. 回答以 **SSE 流式**逐字返回（不是等全部生成完才显示）；
4. 回答末尾附**来源引用**，可点开查看来自哪个文档、哪个分块。

**需要注意**：
- **没配大模型时**发送会被事前拦截并引导到设置页，不会白等；
- 切换会话会自动取消上一条正在生成的回答；
- 多轮历史默认保留最近 20 条消息（可在设置页调整历史上限）。

### 🕸️ 知识图谱页

**界面有什么**：力导向/水球体图谱画布、搜索框（定位实体）、缩放与聚焦控件、右侧实体详情面板、「抽取图谱」按钮。

**你该做什么**：先点「抽取图谱」，再浏览实体与关系；点击节点查看实体详情与命中切片。

**点了之后后台发生什么**：
1. 「抽取图谱」会调用**大模型**从已有分块中抽取实体与关系并入库（需要配置 LLM，未配置会明确提示）；
2. 图谱页展示的是**已入库**的实体关系，空库时为合法空图，不是加载失败；
3. 选中实体可「蒸馏」出该实体的知识卡片（同样需要 LLM）。

**图谱是空的？** 先确认：① 已导入文档；② 已配置大模型；③ 已点过「抽取图谱」。

### 📥 导入页

**界面有什么**：路径输入框（可拖拽）、"选择…"按钮、分组名输入框、递归子目录勾选框、"导入"和"重置"按钮、进度条、结果三栏（成功/跳过/失败）。

**你该做什么**：选择或拖入一个文件 / 文件夹，可选填分组名，点"导入"。

**点了之后后台发生什么**（这是全软件最"重"的一步）：
1. 后端逐文件读取内容（PDF 逐页解析、Word/Excel/PPT 解析、图片 OCR 等）；
2. 按语义把内容切成小块（分块），表格和代码块会被整块保护；
3. 每个分块转成向量（嵌入）；
4. 写入本地向量库；已导入过的文件（内容没变）自动跳过。

**怎么看结果**：
- **成功**：每个文件的文件名 + 分块数 + 大小 + 格式。
- **跳过**：内容与已导入的相同（MD5 去重），不会重复入库。
- **失败**：显示具体是哪个文件、为什么失败（如"加载失败 / 分块失败 / 嵌入失败"）。

**分组是什么**：给这批文档起的**分组名**。留空则归入 `default`。
搜索时填同一个分组名，就只在那一组文档里搜。相当于给知识库分区。

### 🔄 转换页

**界面有什么**：源文件输入框 + "选择文件…"、输出位置输入框 + "另存为…"、格式下拉（md/json/txt/html）、"转换"和"重置"按钮、预览区。

**你该做什么**：选一个源文件（PDF/DOCX/XLSX/PPTX/MD/HTML 等），选目标格式，点"转换"。

**点了之后后台发生什么**：后端解析该文件 → 转成目标格式文本 → 返回内容；**如果指定了输出位置，会直接写文件到那个路径**。

**重要区别**：转换**只是改格式，不进入知识库**——转换结果不会出现在搜索里。
想把文件加入知识库，请走【导入】页。

### 📊 质量看板页

**界面有什么**：分组过滤框 + 刷新按钮；四张概览卡片（文档总数 / 分块总数 / 格式分布 / 质量警告）；左侧分组分布列表；右侧警告列表。

**你该做什么**：点"刷新"，查看知识库整体健康度。

**每张卡片是什么**：
- 文档总数：知识库里有多少个文档。
- 分块总数：所有文档被切成多少块。
- 格式分布：出现过几种文档格式。
- 质量警告：后端基于真实数据算出的问题条数（如"分块数为 0，可能无法检索"、"体积过大建议拆分"）。

**分组分布**：每个分组各有多少文档、多少分块、占用多大空间。

### 🗂️ 文档库页

**界面有什么**：集合过滤框、分页按钮（◀ ▶）、"刷新"、"删除选中"、"重建索引"按钮；左侧文档列表（分页），右侧选中文档的分块预览。

**你该做什么**：浏览已导入文档；选中一个文档看它的分块内容；删除不要的文档；或重建索引。

**重建索引是干嘛的**：把现有分块**重新用嵌入模型计算一遍向量**。
什么时候用：
- 你换了嵌入模型（在设置页改了模型名后）；
- 怀疑向量数据损坏或想整体刷新。
点"重建索引"会提交一个后台任务，进度条显示处理进度。**重建期间不要关软件**。

**"🔍 定位"按钮**：在分块预览里点"定位"，会跳转到搜索页，用该分块的内容作为搜索词，帮你找到相关知识。

### ⚙️ 设置页

**界面有什么**：后端连接（地址、启动超时）、性能（轮询间隔）、模型与分块（嵌入模型、分块参数）、启动选项（自动拉起后端、退出联动终止、后端命令路径、自动导入目录）、**外部组件路径**、外观（浅色/深色主题）、关于；底部"保存"和"恢复上次保存"按钮。

**外部组件路径卡片**（🗂 图标）：管理四类外部资源的存放位置——Poppler（扫描 PDF 渲染）、后端 Python 解释器、离线安装包 wheels、嵌入模型缓存。每一行都可以：

- **📁 浏览选择…**：手动指定位置（弹目录选择框，选中后会先校验必需文件，校验不过不生效）；
- **🔍 自动寻找可用配置**：三级递进自动定位——先查你已配置的路径，再快扫高概率目录（秒级），仍未命中会询问"是否全盘深搜（含 U 盘）"，深搜跳过系统目录、可中途取消，找到后自动写入配置；命中的结果会缓存，下次点"自动寻找"毫秒级直接复用；
- **🔄 重新检测**：刷新全部四行的就绪状态与来源标注（手动配置 / 缓存 / 候选快扫 / 全盘搜索）。

**你该做什么**：一般**不用改**，默认值就能用。需要时才调整：

| 配置 | 作用 | 何时改 |
|---|---|---|
| 后端地址 | 后端服务地址 | 后端端口变了，或改用远程后端 |
| 启动超时 | 等待后端启动的最长时间 | 机器很慢、首次下载模型时可能超时 |
| 嵌入模型 | 向量化用的模型（small/base/large） | 想提高检索精度（模型越大越慢） |
| 分块参数 | 分块的大小/重叠量 | 检索粒度不合适时微调 |
| 自动拉起后端 | 启动客户端时自动启动后端 | 想自己手动启动后端（取消勾选） |
| 退出联动终止 | 退出客户端时关掉后端 | 想退出后后端继续运行 |
| 启动自动导入 | 启动后自动导入某个目录 | 常用目录想开机即用 |

**注意**：修改模型/分块/后端地址等参数后，**需要重启客户端生效**（后端是启动时按这些参数拉起的）。

### 📋 调试日志页

**界面有什么**：实时滚动的日志行、"清空缓冲"、"打开日志文件"、"打开日志目录"按钮。

**你该做什么**：平时不用看。**当某个操作出错、状态栏提示"详见后端日志"时**，来这里查原因，或点"打开日志文件"用文本编辑器打开完整日志。

## 四、术语速查表

| 术语 | 含义 |
|---|---|
| 集合 (Collection) | 文档的分组名。导入时指定，搜索/看板可按组过滤；留空归入 `default` |
| 分块 (Chunk) | 文档被切开的一个个小片段，是搜索的最小单位 |
| 嵌入 / 向量 (Embedding) | 把文本转成数字向量，让计算机能算"语义相似度" |
| 相似度分数 | 0~1，搜索结果与搜索词的匹配程度，越高越相关 |
| 混合检索 | 向量相似度 + 关键词（BM25）两路结果融合排序 |
| 重建索引 (Reindex) | 用嵌入模型重新计算所有分块的向量 |
| 后端 (Backend) | 本地 Python 服务（默认 `localhost:8765`），负责解析/分块/嵌入/检索/存储 |
| MD5 去重 | 内容相同的文件只入库一次，重复导入会被"跳过" |

## 五、常见问题

**Q：搜索没有结果，为什么？**
A：先到【导入】页确认文档已成功导入（没有全在"失败"栏）；再看集合是否匹配（搜索页集合要留空或与导入时一致）；最后可降低"最低相似度"或换关键词。

**Q：导入很慢 / 进度条一直转？**
A：首次用某个模型需要下载（国内走镜像，几分钟）；PDF 扫描件要逐页 OCR，大文档耗时正常。导入大文件时，进度条会按文件内阶段推进（解析 → 切片 → 向量嵌入 → 写入索引），下方会实时显示当前阶段与百分比（如"正在向量嵌入（37%）"），完成后会显示成功/跳过/失败明细。

**Q：改了设置好像没生效？**
A：大部分参数（模型、Key、分块、检索等）**保存后立即推送生效**，无需重启。只有后端连接地址、启动命令等底层参数变更后需要重启后端（保存时会自动提示）。

**Q：托盘图标显示"离线"？**
A：后端没起来或连不上。若设置了"启动时自动拉起后端"，稍等片刻；若取消了，请手动运行 `doc2mind serve` 后再打开客户端。

**Q：删除文档会怎样？**
A：会同时删除该文档的全部分块和向量（释放空间），不可恢复，删除前有确认弹窗。
