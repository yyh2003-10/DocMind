💡 灵感框架

本方案参考的三大先进框架及其核心贡献

🧠

Hermes Agent

核心贡献：自改进学习循环——从已完成任务自动创建可复用"技能"，FTS5 会话搜索，后台自我审查，MEMORY.md + USER.md 双层记忆。

本方案采用：用户记忆层设计、后台记忆提取、渐进式披露模式。

💾

Mem0

核心贡献：提取→检索两阶段管线，多信号融合检索(语义+关键词+实体)，内置图记忆，LoCoMo 92.5 分。

本方案采用：LLM 事实提取、去重逻辑、多信号检索思想。

🏭

Hive

核心贡献：生产级 Agent 脚手架——自愈机制(分析→进化→重部署)、检查点恢复(park/resume)、三级成本强制执行、Sentinel 人机协作。

本方案采用：检查点恢复、成本追踪、工具调用自愈、Agent 工作流。

🗺️ 实施阶段

5 个阶段、15 个改进项、9.5 周完成

PHASE 1 · P0 关键

🧠 跨会话记忆层

📅 2 周 · 用户感知最强的提升
让 AI 助手"记住"用户——跨会话记住偏好、经验、纠正，不再每次都从零开始。
  • +UserMemoryService — SQLite 存储 + FTS5 搜索，2,200 字符有界记忆
  • +SessionSearchService — 所有历史对话全文存储，支持跨会话回顾
  • ✎ChatViewModel 集成 — 发送前注入相关记忆，结束后异步提取新事实
  • +后台记忆提取 — 规则提取(零成本) + 可选 LLM 提取
  • ◎记忆面板 UI — 输入框上方"🧠 记忆"图标，点击展开管理
  • ◎设置页集成 — 记忆开关、容量配置、自动提取选项
  • ◎消息长按菜单 — "记住这个"直接存入用户记忆
PHASE 2 · P1 可靠性

🛡️ 可靠性提升

📅 1.5 周 · 生产级体验
长时间操作中断可恢复，工具调用失败自动调整策略。
  • +CheckpointService — 操作检查点：OCR/嵌入/重索引前保存状态
  • +恢复确认对话框 — 启动时检测未完成操作，询问是否继续
  • +ToolCallResilience — 搜索自愈：空结果时自动放宽阈值重试
  • +OCR 失败重试 — 首次失败自动切换 CPU/GPU 模式重试
  • ◎恢复进度条 — 从断点显示剩余进度
PHASE 3 · P1 成本

💰 成本追踪与控制

📅 1 周 · 用户信任
实时追踪 LLM 调用费用，预算接近上限时预警。
  • +CostTracker — SQLite 记录每次 LLM 调用的 token 数和费用
  • +费用聚合查询 — 今日/本月费用、按模型分组、趋势图表
  • +预算阈值告警 — 80% 黄色警告，95% 红色警告，100% 暂停
  • ◎状态栏费用 — 显示"今日 $0.12 · 本月 $3.45"
  • ◎对话费用标签 — 右下角小字"本次约 $0.003"
  • ◎设置页费用面板 — 月度预算设置、费用图表
PHASE 4 · P2 改进

🔄 自我改进循环

📅 2 周 · 越用越好
利用用户反馈改进回答质量，从对话中学习偏好模式。
  • +FeedbackLoopService — 点赞/点踩反馈记录与分析
  • +反馈摘要生成 — 定期分析：常见不满意原因、偏好模式
  • +自适应系统提示 — 基于反馈动态调整回答风格指令
  • +回答模式学习 — 从点赞消息中提取"好的回答"特征
  • ◎反馈分析面板 — 设置页显示满意度趋势、改进建议
  • ✎ChatViewModel — 长按消息菜单增加"标记为好的回答"
PHASE 5 · P2 高级

🤖 Agent 工作流

📅 3 周 · 高级能力
AI 自主规划并执行多步骤复杂任务，如"分析文档并生成报告"。
  • +AgentWorkflowEngine — 意图分析 + 多步骤任务规划
  • +工作流执行器 — 逐步执行、进度追踪、失败处理
  • +步骤依赖管理 — 前序步骤结果自动传递到下一步
  • +人工确认节点 — 危险操作暂停等待用户确认
  • ◎Agent 模式开关 — 输入框新增"🤖 Agent 模式"切换
  • ◎步骤进度条 — "Step 3/5: 正在提取关键指标..."
  • ◎执行日志面板 — 展示完整工作流执行过程
